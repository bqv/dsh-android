# DSH for Android v0.3.0

A feature release. The transcript gets its links working, the composer stops losing
what you typed, and the app can finally talk to DeepSeek about money.

## Links work, everywhere they appear

Only `[text](url)` was ever linked, and every other form this model actually writes
rendered as dead text. Measured against real transcripts before touching anything:
across a sample of sessions, **zero** CommonMark angle autolinks and **198** backticked
URLs in one session alone. All four gaps are closed:

- **A bare URL** is a link (`https://…`, `http://…`, `www.…`), by GFM's rule: from a
  word boundary, with the sentence's own punctuation left out and a bracket that
  belongs to the path kept.
- **A code span that is nothing but a URL** — `` `https://x.dev/docs` `` — is a link. A
  span with anything else in it stays code: `` `curl https://…` `` is a command, and
  linking half of it would misrepresent it. Punctuation inside the backticks is kept,
  because there the characters are deliberate.
- **A URL inside emphasis** is a link. `**https://github.com/…/pull/1451**` was bold and
  dead, because emphasis was consumed as one opaque styled run. Emphasis now parses its
  content recursively, so a code span inside it stays code and `BOLD` over `ITALIC`
  becomes `BOLD_ITALIC` instead of one of them being dropped.
- **Reasoning renders as markdown**, not as plain text — which is where this model puts
  most of its URLs. Thinking gets the same renderer, and the same links, as the answer.

## The composer stops losing things

- **Drafts persist.** They were `rememberSaveable`, which survives a rotation but not a
  restart, a swipe-away, or a session switch. They now live on disk, keyed by session —
  and the **deferred new-session screen** has a key of its own, so a half-written prompt
  on the hero survives too.
- A draft typed on that screen **follows the session it turns into**, whether that is
  your send materialising it or the app's own auto-open picking a session while you are
  still typing.
- **A message taller than the screen is no longer chased.** Following used to slide a
  long answer's own beginning off the top while the next token dragged you back down; at
  the instant the row outgrows the viewport, following stops, which is the one place its
  top is exactly at the top of the screen.

## Back is a gesture, not an exit

- **Back closes what is open** — the Files panel, then a non-Chat view — and from a
  subagent it **opens its parent**, walking the stack.
- With nothing left to dismiss it asks, in a **dialog** rather than a toast: Back again
  cancels, and only Exit leaves. The dialog says what closing does *not* do — the agent
  keeps working, jobs keep running, a waiting question stays.

## DeepSeek: what it cost, what is left, top up

- The token panel gains **Cost (off-peak – peak)**: the same tokens priced at both ends
  of DeepSeek's tariff, because no per-request timestamp reaches a client and one number
  would pretend to a precision the data lacks. Prices are DeepSeek's published CNY list
  (Flash ¥0.04/2/8 and Pro ¥0.30/9/27 per 1M at peak, off-peak half), with the date it
  was read printed underneath. A route without a published price draws **no row**.
- **Balance & top up** reads `GET /user/balance` with an API key you paste there — the
  only account call DeepSeek publishes, and the one request this app makes that does not
  go to your host. The key is stored in the app's encrypted preferences and sent only to
  `api.deepseek.com`. Top up opens `platform.deepseek.com/top_up` in the browser: there
  is no top-up API, and a payment form in an app would be inventing one.

## Shared into, and drawn

- **Share to DSH** from the system share sheet: any file type, one or several, lands in
  the open session's composer as an attachment — the same path the `+` button takes. A
  share can start the app from cold, so the files wait until it is connected and has a
  session to stage them into.
- **Image previews render**, and an **SVG comes both ways**: the drawing, with the header
  toggling to the markup. The format is decided from the path, which is what makes the
  read choice possible at all — a raster image is fetched as bytes
  (`workspaceFiles/readBytes`, one bounded window) and everything else as text, and the
  text endpoint refuses non-UTF-8 outright.
- A subagent's **host shell is its ancestor's**, so a parent and every subagent under it
  share one shell and one history. Measured before changing anything: the host never
  makes a subagent a Workspace member, so the existing "shared by members" rule never
  fired for one.

## The drawer, and the desk

- **Automation runs have their own section**, with a schedule glyph, instead of padding
  out a Workspace's list — and **Ungrouped** has its own glyph too.
- **Opening a session withdraws its notifications**: the alert existed to bring you
  there, and you are there. Resuming the app onto a session does the same.
- **The terminal's own font** is Inconsolata, bundled (SIL OFL), with box-drawing and
  block characters complete — a terminal's font is not a matter of taste.

## What is not verified

The emulator was unusable for most of this cycle (host load high enough that it ANR'd on
anything, including the system UI), so several screens were built and tested by unit
test rather than by eye. Stated plainly rather than left to be discovered:

- **The link taps** are pinned by parser tests; that a tap opens the browser was last
  confirmed on a device in v0.2.1.
- **The share sheet chip**, the **image and SVG previews**, the **automations section**,
  the **draft persistence** and the **stop-at-the-top scroll** have not been looked at on
  a device by the author. Their logic is under test; the pixels are not.
- Re-attach after a network drop remains unverified, as in v0.2.1: the emulator's
  `svc wifi`/`svc data` do not touch the path this app uses.
