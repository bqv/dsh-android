# DSH for Android v0.2.1

The terminal gets the attention of a reader, and the app stops losing the two
things a terminal is for: text you paste in, and text you copy out.

## Ctrl-C and Ctrl-D from a soft keyboard's own Ctrl key

v0.2.0's notes said this worked. It did not: pressing Gboard's `Ctrl` and then `c`
or `d` typed a literal `c` or `d`. The panel's own Ctrl cap worked, which is how
the claim survived review — the two paths look identical from the outside.

The handler refuses an input method's Ctrl bit on purpose, and that part was
right: Gboard sets `META_CTRL_ON` on **every** key event it synthesises, so
honouring the bit turns the word `cat` into `^C ^A ^T`. What was missing is that
Gboard's `Ctrl` button is a key in its own right. The phone log shows what it
sends:

```
KEYCODE_CTRL_LEFT  ACTION_DOWN   metaState=META_CTRL_ON|META_CTRL_LEFT_ON
KEYCODE_C          ACTION_DOWN   metaState=META_CTRL_ON|META_CTRL_LEFT_ON   unicode=0
KEYCODE_C          ACTION_UP
KEYCODE_CTRL_LEFT  ACTION_UP
```

A plain `x`, by contrast, never arrives as a key event at all — it comes through
`commitText`. So the `Ctrl` key-down is the signal, and the modifier bit means
something only for the key that follows it. That is now what decides a chord: the
keyboard's own Ctrl key, one-shot, read and cleared by the next event, with the
bit still meaningless on its own.

Both directions are pinned by a test: the new rule sends `^C` for that sequence,
and the untrusted bit without a preceding Ctrl key-down stays text, so the `cat`
regression cannot return through this door.

## The terminal's highlight was two pixels off its own grid

`htop`'s selected row was a 37px band against a 37px cell pitch, but sitting 3px
high, so its glyphs — which *are* centred in the cell — hugged the band's bottom
edge. The band was painted by the text layout's span background, whose box is the
font's line box, not the cell; the block cursor draws a rect on the cell grid, so
the two could never agree. Backgrounds are now rects on the character grid, the
same maths the cursor uses, and spans carry foreground only.

Measured before the fix: band 866..902 against a cell grid starting at 869.

## A bell now notifies

BEL was dropped on the floor. It is counted in the emulator — an OSC *terminator*
is not a bell, which matters because `htop` sets its window title on every
repaint, and the parser consumes that one before the C0 handler sees it — and the
panel turns a rise in the count into the same attention notification a question
gets, deep-linked to the session and suppressed while that session is on screen.

## Paste, and selecting chat text

Neither worked, and neither was a mapping bug.

- **Paste** could not work from a soft keyboard at all: the editor is `TYPE_NULL`,
  which is what stops Gboard routing keystrokes through its composer and
  autocorrecting `vim` into `vI'm`. An input method's clipboard needs an editor to
  paste *into*, so its paste button has nothing to act on — three presses in a
  phone log produced no callback of any kind, not even a `commitText`. Termux has
  the same constraint and solves it the same way: the app pastes. The key row
  gains a **Paste** cap, and pasted text goes out CR-delimited (a terminal's Enter
  *is* CR) and wrapped in `?2004` bracketed-paste markers when the program asked
  for them — without them an editor re-indents a paste and a shell runs it line by
  line as it arrives.
- **Chat text was not selectable**: Compose needs a `SelectionContainer` and the
  transcript had none, so no answer, tool output or command could be copied. Each
  row has its own, rather than one around the list, because a selection spanning
  two lazily-composed items loses its ends when either is recycled.

## Inconsolata

The terminal now bundles Inconsolata (SIL OFL, see `docs/licenses/`) in regular
and bold. A terminal's font is not a matter of taste: box-drawing and block
characters have to be in the same face at the same advance, or a TUI's frame comes
apart. Inconsolata covers both blocks completely (measured from the font's own
cmap: 100% of U+2500–257F and U+2580–259F), and its narrow advance fits more
columns on a phone. Its arrows (13%) and braille (0%) fall back per glyph, which
is why the alternative on the table was DejaVu Sans Mono — that one has arrows and
Greek but is three times the size.

## Under the hood

- 233 JVM tests, including the new bell rule: a BEL is counted, an OSC terminator
  is not.
- A debug build now logs every alert it posts or suppresses, because each way a
  notification can fail is silent.
